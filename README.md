## Why concept demos

A small business owner can't picture a website from a proposal. A working page for their own kind of business, with believable content and honest labelling, is a faster conversation. Each site is built with its own palette and type, matched to the business rather than to a template.

## Run one locally

Every folder is plain static files. Open its `index.html` in a browser, or serve the repo:

```bash
npx serve .
```

`vercel.json` turns on trailing slashes so each folder deploys as its own page.
